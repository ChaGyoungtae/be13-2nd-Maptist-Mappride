# 📌 프로젝트 개요
<br>

## 사용자 맞춤형 지도를 제작할 수 있는 웹 애플리케이션
<br>

> 사용자가 자신만의 지도를 제작하고, 장소를 카테고리별로 정리하여 관리할 수 있는 웹 애플리케이션입니다. 단순한 길찾기 지도에서 벗어나, 개인 맞춤형 장소 기록과 공유에 초점을 맞추고 있습니다.

> 내가 다녀 본 맛집, 분좋카, 데이트 장소 등을 기록하고 관리하여 다른 사람과 공유할 수 있는 플랫폼이 있다면 어떨까하는 생각에서 시작했습니다.

> 또한 맛집 하나를 찾더라도 광고와 홍보가 넘쳐나는 세상에서 다른 사람들이 경험을 바탕으로 추천하는 장소들을 공유하며
> 다른 사람들의 취향을 확인하고 나도 그러한 장소를 체험하거나
> 나와 비슷한 취향을 가진 사람들이 추천하는 장소를 확인하고자 하는 생각으로 어플리케이션을 제작을 기획하게 되었습니다

<br><br>

# 📌 주요 기능
### 회원 관리
- 간편한 소셜 로그인 (Google, Kakao, Naver 등)

- 사용자 프로필 관리
  
 <br>

### 카테고리 및 장소 관리
- 카테고리 생성/수정/삭제

- 각 카테고리에 장소 추가 가능

- 장소는 이름 수정 및 삭제 가능

<br>

### 장소 상세보기 및 소통 기능
- 장소별 사진과 설명 추가 가능

- 다른 사용자가 장소를 열람하고 댓글 작성 가능

- 장소를 공유하여 지도 기반의 커뮤니티 형성
