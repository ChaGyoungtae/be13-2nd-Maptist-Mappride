# 📌 프로젝트 개요
<br>

## 사용자 맞춤형 지도를 제작할 수 있는 웹 애플리케이션
<br>

> 사용자가 자신만의 지도를 제작하고, 장소를 카테고리별로 정리하여 관리할 수 있는 웹 애플리케이션입니다. 단순한 길찾기 지도에서 벗어나, 개인 맞춤형 장소 기록과 공유에 초점을 맞추고 있습니다.

> 내가 다녀 본 맛집, 분좋카, 데이트 장소 등을 기록하고 관리하여 다른 사람과 공유할 수 있는 플랫폼이 있다면 어떨까하는 생각에서 시작했습니다.

> 또한 맛집 하나를 찾더라도 광고와 홍보가 넘쳐나는 세상에서 다른 사람들이 경험을 바탕으로 추천하는 장소들을 공유하며
> 다른 사람들의 취향을 확인하고 나도 그러한 장소를 체험하거나
> 나와 비슷한 취향을 가진 사람들이 추천하는 장소를 확인하고자 하는 생각으로 어플리케이션을 제작을 기획하게 되었습니다

<br><br>

# 📌 주요 기능

### 1️⃣ 회원 관리
- 간편한 소셜 로그인 (Google, Kakao, Naver 등)

- 사용자 프로필 관리
  
 <br>

### 2️⃣ 카테고리 및 장소 관리
- 카테고리 생성/수정/삭제

- 각 카테고리에 장소 추가 가능

- 장소는 이름 수정 및 삭제 가능

<br>

### 3️⃣ 장소 상세보기 및 소통 기능
- 장소별 사진과 설명 추가 가능

- 다른 사용자가 장소를 열람하고 댓글 작성 가능

- 장소를 공유하여 지도 기반의 커뮤니티 형성

| 권지민 | 이번 프로젝트를 진행하면서 처음으로 Spring을 다뤄보았는데, 많이 배웠습니다. 소셜 로그인, 알림 등 어려운 부분은 다른 팀원분들이 최선을 다해주셔서 더 퀄리티 있는 프로젝트가 완성된 것 같아서 감사합니다. |<br/>
| 이성일 | DB,spring/boot, jpa 공부가 많이 필요할 거 같다고 느꼈습니다. vue도 다뤄보니 꽤 흥미로웠습니다. 팀원들이 묵묵히 열심히 해줘서 결과물이 잘 나왔던 거 같습니다. |<br/>
| 이창신 | 수업 때 배운 것과 프로젝트 작업 시 실전에서 사용하는 것과 많이 달라서 힘들었다. 백엔드에서는 데이터를 어떻게 받고 어떻게 수행되는지 이해하기 어려웠고, 자바로 구현하면서 복잡한 구조에 다양한 데이터 타입까지 머리를 어지럽게 만들었다. 팀원들이 도와주고 알려주면서 기본적인 CRUD 정도는 조금이나마 습득할 수 있게 되었다. 학습의 목적으로 JPA로 구현하도록 했는데 이를 세팅하는 것은 비교적 수월했지만 내용을 작성하면 작성할수록 공부할 내용이 까도 까도 계속 나왔다. 더 공부했어야 했는데 프로젝트를 수행하면서 추가적인 공부를 소홀히 한 것 같아 나 자신을 뒤돌아볼 때 너무나 부족한 실력인 것 같다. 나 스스로 발전할 필요를 느꼈다. |<br/>
| 차경태 |  기본적인 JPA를 이용한 DB와의 통신으로 원하는 데이터를 생성, 수정, 조회, 삭제 하는 기술 뿐만 아닌 Spring Security + JWT + OAuth 2.0을 이용한 소셜로그인, 공용DB 연결을 위한 Amazon RDS, 공용 redis 연결을 위한 Amazon EC2, 이미지 파일 저장을 위한 S3 버킷 등 좀 더 어려운 백엔드 기술을 다룰 수 있게 된 것 같아서 매우 값진 경험을 한 것 같습니다. 또한 이번 프로젝트를 통해 github-flow의 풀리퀘스트 방식에 대해서도 잘 알게 되는 계기가 되어 기술적인 측면만이 아닌 협업에 대한 스킬도 많이 배운 프로젝트인 것 같습니다. |<br/>
| 최유진 | Java와 Spring Framework, JPA를 사용해 백엔드를 구축하고 해당 기술에 대한 이해도가 높아졌습니다. 특히 JPA를 활용한 데이터 모델링은 처음엔 다소 어려웠지만 점차 익숙해졌고 DB와의 연동이 어떻게 이루어지는지에 대한 이해도가 깊어졌습니다. |
